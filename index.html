01Focus

Three axes, kept independent.

Everything the lab runs is built from the same three kinds of parts: a model of the world to reason against, agents that do the work, and verifiers that hold the work to a standard.

/01

World models

Deep, queryable models of real-world domains — starting with Manhattan real estate, building by building — that give agents ground truth to reason and act against instead of guessing from thin context.

/02

Agent operations

Multi-agent pipelines that run daily work end to end — leasing paperwork from application to signature-ready package, editorial desks that draft and revise long-form content to publication grade.

/03

Verification & evals

Independent judges, frozen replay benchmarks, and post-write checks. The agent that writes is never the agent that grades — and no system ships on a demo and a good feeling.

03Approach

Orthogonal by design.

The lab is named for its operating principle: the axes stay independent. Four rules, applied to everything we ship.

/01

Generation ⊥ verification

The writer never grades its own work. When a check fails, the failure makes the checks better — it doesn't get folded back into the writer's prompt until the writer learns to game the test.

/02

Frozen benchmarks, honest claims

Before we tune, we freeze the test. An improvement only counts if it's measured against a benchmark that couldn't move to produce it — and claims never outrun the data.

/03

Production is the demo

Systems run inside operating businesses, on live work, with real consequences. If it only works in a notebook, it doesn't work.

/04

Small systems, sharp seams

Independent components with explicit contracts. They compose cleanly, they fail legibly, and any one of them can be replaced without renegotiating the whole.
